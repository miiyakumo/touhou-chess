# 幻翼合体：空袭升级｜产品需求文档

## 1. 项目概述

### 1.1 产品定位

《幻翼合体：空袭升级》是一款 Minecraft 同人题材、单机运行、轻量网页 STG。它借鉴“等级越高，敌人名字越长、组合越离谱”的页游梗，把核心体验落在三件事上：移动放风筝、敌人能力合体、数值不断膨胀。

### 1.2 项目边界

这是一个简单且非商业化的同人小游戏。第一版不包含账号、联网服务、商城、广告、付费、排行榜、社交和复杂养成系统。

### 1.3 目标用户体验

玩家不需要阅读长说明或学习复杂按键。进入战斗后，只要移动就能自动攻击；玩家通过保持距离、绕开预警、诱导敌人技能来完成战斗。每次升级都应让玩家看到明显的数值变强和画面反馈，同时感受到新敌人的压力更高。

## 2. 核心玩法需求

### 2.1 操作

- 桌面端使用 WASD 或方向键移动。
- 移动端使用单指拖动或虚拟摇杆移动。
- 玩家自动锁定附近敌人并持续攻击。
- 不要求鼠标瞄准、技能快捷键或复杂组合操作。
- 玩家必须能够边移动边攻击，形成放风筝玩法。

### 2.2 战斗循环

1. 玩家进入当前波次。
2. 敌人按配置出现并使用对应能力。
3. 玩家移动躲避攻击，自动武器持续输出。
4. 击杀敌人掉落经验、材料或装备表现。
5. 经验达到阈值后升级，玩家数值提高。
6. 波次推进，敌人获得新部件或提高数量与属性。
7. 新合体首次作为 Boss 登场；旧 Boss 在后续波次降级为精英或普通敌人。
8. 玩家死亡后可立即重开，保留最高进度记录。

### 2.3 胜负

- 普通波次没有复杂任务目标，主要目标是存活并击败敌群。
- 每个阶段末尾出现合体 Boss。
- 玩家生命归零时进入结算页，可重新开始。
- Boss 被击败后进入下一阶段并展示下一种合体。

## 3. 敌人能力需求

敌人部件必须同时改变外观和行为。新部件不会替换旧能力，而是在已有能力上追加能力。

| 部件 | 能力 | 预警与应对 |
| --- | --- | --- |
| 幻翼 | 追踪接近、近身扑击 | 保持距离并横向移动 |
| 小僵尸骑士 | 贴身挥砍、短距离冲锋 | 绕圈或冲刺拉开距离 |
| 苦力怕 | 接近后蓄力爆炸 | 出现爆炸圈时立即撤离 |
| 烟花 | 高速直线冲撞 | 看到方向预警后横向闪避 |
| 凋零 | 三方向骷髅弹、散射弹幕 | 穿过弹幕间隙 |
| 监守者 | 蓄力直线音波 | 离开瞄准线 |

攻击必须可预测、可躲避。所有强攻击都需要预警线、预警圈、蓄力动作或明显音效。不能用无预警的高伤害覆盖玩家。

## 4. 成长需求

### 4.1 玩家成长

玩家升级后至少提升以下一项：

- 攻击伤害
- 射速
- 弹道数量
- 生命上限
- 移动速度（设置上限）

成长反馈优先采用数字、闪光、经验球和装备掉落，不依赖长文案。

### 4.2 敌人膨胀

敌人生命、伤害、数量和能力随阶段上升，整体增长速度高于玩家。为了保留走位空间，移动速度、攻击频率和同屏弹幕数量设置上限。

### 4.3 Boss 降级

新形态首次出现时是 Boss，后续阶段按以下顺序降级：

1. Boss：完整血量和完整招式。
2. 精英：缩小体型，减少生命和技能数量。
3. 普通怪：只保留核心攻击方式，混入敌群。

## 5. 视觉与内容需求

### 5.1 全面 Minecraft 化

以下内容必须统一为方块像素风：

- 玩家飞行器
- 幻翼、小僵尸、苦力怕、烟花、凋零、监守者
- 三叉戟、骷髅弹、音波、爆炸和冲撞效果
- 经验球、材料、装备掉落
- 末地、下界或虚空战场
- Boss 合体后的新增部件

移除 Emoji、通用太空飞船和与 Minecraft 无关的现代 UI 图标。素材使用原创绘制或可再分发的同人素材，不直接提取官方游戏文件。

### 5.2 文字约束

战斗 HUD 只保留：生命、经验、等级、波次、Boss 名称和必要的数字反馈。删除假聊天、活动页、长说明和大段页游文案。土气感来自：

- 粗金边与高饱和配色
- 过大的暴击数字
- 附魔闪光和爆炸碎片
- 装备喷落与经验球飞散
- Boss 登场时体型和特效突然膨胀
- 旧 Boss 变小怪带来的反差

## 6. 交付物

- 可直接运行的网页游戏
- 桌面端和移动端移动操作
- 自动攻击与放风筝战斗
- 至少六种敌人部件能力
- 至少三个阶段 Boss，并支持旧 Boss 降级
- 本地进度和最高记录
- 开始、战斗、暂停、结算、重开流程
- 源代码、运行说明、素材说明
- 已知问题清单

## 7. 非目标

- 账号和云存档
- 联机、PVP、排行榜
- 商城、充值、广告
- 复杂装备背包和技能树
- 大量剧情文本
- 高精度 3D 模型

## 8. 参考素材约束

项目美术参考用户提供的三张方块合体图：飞行器作为底座，怪物作为可拆分部件，攻击武器和特效作为外挂模块。参考重点是构成方式、等距方块质感、紫色背景和部件夸张比例；水印、账号名和图片中的说明文字不进入游戏。具体怪物组合与素材拆分见 [`monster-roster.md`](monster-roster.md)。
