# 幻翼合体：空袭升级｜游戏设计文档

## 1. 设计支柱

### 放风筝

玩家的主要动作是移动。自动武器持续攻击最近目标，玩家通过保持距离、绕圈、穿过弹幕间隙来生存。移动必须有价值：停在原地会受到追击、冲撞或爆炸威胁。

### 合体进化

敌人形态是能力的可视化。部件越多，外观越大、名称越长、攻击组合越复杂。每获得一个部件，都至少增加一种可识别的攻击行为。

### 数值降维

玩家从较小数字开始成长；敌人增长更快。刚刚需要认真处理的 Boss，在后续波次会缩小并混入普通怪群，制造“前期 Boss 变小怪”的爽感。新的合体 Boss 负责重新建立压力。

## 2. 第一阶段切片

### 关卡

- 名称：末地试飞场
- 时长：约 3 分钟
- 场景：紫色虚空、末地岛碎片、方块粒子
- 玩家：方块飞行器，自动发射三叉戟弹
- 控制：WASD、方向键或移动端拖动

### 关卡流程

| 时间 | 内容 | 设计目的 |
| --- | --- | --- |
| 0:00–0:30 | 幻翼普通怪 | 教玩家保持距离 |
| 0:30–1:00 | 幻翼数量增加 | 建立放风筝节奏 |
| 1:00–1:40 | 小僵尸骑士·幻翼 Boss | 引入贴身挥砍和冲锋 |
| 1:40–2:10 | 小僵尸骑士·幻翼变为精英与普通怪 | 验证 Boss 降级爽感 |
| 2:10–3:00 | 苦力怕·幻翼 Boss | 引入爆炸预警和区域躲避 |

## 3. 玩家设计

### 飞行器

方块核心、三叉戟炮、幻翼翅膀、红石推进器和烟花尾部组成。部件清楚可见，升级时通过增加部件、改变发光颜色或扩大弹道表现强化感。

### 基础属性

| 属性 | 初始值 | 上限或约束 |
| --- | ---: | --- |
| 生命 | 100 | 按阶段增长 |
| 移动速度 | 220 | 不超过基础值的 1.5 倍 |
| 攻击伤害 | 8 | 随等级增长 |
| 射击间隔 | 0.35 秒 | 不低于 0.12 秒 |
| 自动锁定距离 | 全屏 | 只锁定可见目标 |

## 4. 敌人设计

### 幻翼

- 角色：基础近战敌人
- 行为：从远处接近，短暂蓄力后俯冲
- 预警：俯冲方向出现淡紫色线
- 后续定位：普通怪

### 小僵尸骑士·幻翼

- 角色：第一阶段 Boss
- 行为：保留幻翼俯冲，追加骑士横向冲锋和近战挥砍
- 预警：冲锋前出现红色方向箭头
- Boss 击败后：缩小并作为精英或普通怪出现

### 苦力怕·幻翼

- 角色：第二阶段 Boss
- 行为：保留幻翼接近，靠近玩家后蓄力爆炸
- 预警：脚下出现逐渐扩大的爆炸圈，蓄力期间移动减慢
- Boss 击败后：作为会飞的爆炸普通怪出现

### 烟花幻翼

- 角色：冲撞型追加部件
- 行为：沿直线高速冲撞，撞击后释放烟花碎片
- 预警：出现彩色烟花轨迹和冲撞方向

### 凋零·闪电苦力怕·幻翼

- 角色：中后期合体 Boss
- 行为：三向骷髅弹、落雷区域、爆炸接近
- 预警：三个方向分别使用不同颜色标记，避免信息混淆

### 监守者·凋零·闪电苦力怕·幻翼

- 角色：高阶段终极 Boss
- 行为：直线音波、三向弹幕、爆炸区和俯冲
- 预警：音波蓄力时出现贯穿战场的矩形瞄准线

## 5. 反馈设计

### 必须有

- 玩家受伤时短暂闪白和击退
- 敌人命中时显示大号伤害数字
- 暴击时使用金色数字和更强粒子
- 升级时经验球聚拢、玩家外框闪光
- Boss 登场时体型放大、屏幕轻微震动
- 爆炸、冲撞、音波都有独立轮廓和预警

### 不使用

- 长篇系统公告
- 假聊天频道
- 复杂任务文字
- Emoji 作为正式游戏素材
- 无法辨认的多色粒子堆叠

## 6. 界面

战斗 HUD 只保留：

- 左上：生命条、经验条、等级
- 顶部：当前波次
- 顶部中央：Boss 名称和血条
- 右上：击败数和掉落数量
- 战场内：预警线、预警圈、伤害数字

开始页和结算页可以有少量标题文字，战斗中不放大段说明。

## 7. 数值模型

建议使用阶段倍率：

- 玩家攻击力：`基础攻击 × (1 + 等级 × 0.08)`
- 普通敌人生命：`基础生命 × 阶段倍率 × 波次倍率`
- Boss 生命：`普通敌人生命 × 12–20`
- 敌人伤害：比玩家生命增长略快
- 敌人速度：随阶段增加，但设置绝对上限

数值目标不是精确平衡，而是制造明显的“数字变大”和“敌人仍然危险”。最终必须通过实际试玩调整，确保预警出现后玩家有足够时间反应。

## 8. 实施顺序

1. 将当前页面拆分为战斗逻辑、敌人配置、素材、HUD 和存档模块。
2. 实现玩家移动、自动锁敌、弹道、碰撞和死亡重开。
3. 实现幻翼、小僵尸骑士、苦力怕三种能力，并完成第一阶段切片。
4. 加入 Boss 降级机制和阶段倍率。
5. 替换所有 Emoji 和通用图形，制作统一 MC 方块像素素材。
6. 加入烟花、凋零、监守者能力与预警。
7. 调整 HUD，删除多余文字，补足数值和视觉反馈。
8. 做桌面端、移动端和多怪同屏测试。
9. 补充运行说明、素材说明和已知问题清单。

## 9. 验收标准

- 玩家仅靠移动即可持续自动攻击。
- 幻翼、骑士、苦力怕的能力可清楚区分。
- 所有高伤害技能都有可读预警。
- 至少一个早期 Boss 能在后续变成普通怪。
- 玩家数值和敌人数值都能明显膨胀。
- 正式素材中不再使用 Emoji。
- 战斗界面没有假聊天和长说明。
- 刷新页面不会导致程序报错，死亡后可立即重开。
