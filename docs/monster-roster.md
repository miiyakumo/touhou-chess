# 幻翼合体：空袭升级｜怪物与美术设定

## 1. 参考图提炼

参考图的核心不是把几个角色简单叠在一起，而是把 Minecraft 生物当成一套可以安装在方块机械上的部件：

- 飞翼、爪、头颅和武器都能成为飞行器的结构件。
- 僵尸等生物负责“骑乘者”或驾驶舱，形成荒诞的机械坐骑感。
- 凋零、监守者等大型生物适合做底盘、装甲或动力核心。
- 三叉戟、烟花、骷髅弹、闪电和冰霜等物品负责表达攻击模块。
- 所有组合都采用等距方块视角，底部有明显阴影，部件边缘用附魔色或高亮像素勾边。

图片中的水印、账号名和说明文字不是游戏内容。正式素材不直接使用这些图片，也不直接提取官方游戏文件。

## 2. 统一美术规则

### 2.1 造型

- 使用 Minecraft 式方块、阶梯边和低多边形体块。
- 每个怪物组合由“底盘 + 核心 + 部件 + 武器”组成，部件之间要有机械连接或方块支撑。
- 不追求真实比例；允许头颅过大、翅膀过宽、武器过长，制造廉价页游式夸张。
- 组合后必须一眼看出原始生物。不要把部件融合到无法辨认。

### 2.2 色彩

- 背景：紫色虚空、末地灰紫、下界暗红。
- 普通部件：使用原始生物的主色。
- 新增能力：用高亮色表达，例如爆炸橙、凋零紫黑、监守者青蓝、烟花红白。
- Boss：部件越多，颜色越杂，但主色不超过三种，避免看不清预警。

### 2.3 动画与反馈

- 部件加入时，从画面边缘飞入并卡在方块底座上。
- 受击时只闪烁受击部件，而不是整只怪物白屏。
- 攻击前先让对应部件动作明显，例如翅膀收拢、苦力怕闪烁、凋零头颅转向、监守者胸口亮起。
- 爆炸、冲撞和音波都必须有独立轮廓，不用一团泛光覆盖战场。

## 3. 组合规则

每个组合最多使用四类槽位：

1. **底盘**：决定移动方式和体型，例如幻翼翅膀、凋零骨架、监守者胸腔。
2. **驾驶者**：决定近战行为，例如小僵尸、骷髅、猪灵。
3. **攻击模块**：决定远程或区域攻击，例如苦力怕、凋零头、发射器、烟花。
4. **强化模块**：决定特殊效果，例如闪电、末影、冰霜、蜘蛛网。

旧部件能力保留，新部件只追加行为。组合的名称按部件加入顺序变长。

## 5. 组合创意方向

### 5.1 骑乘型

将小僵尸、骷髅或猪灵放在大型飞行底盘上。骑乘者的动作是近战来源，底盘负责移动。玩家看到骑乘者抬手时就知道要挥砍或冲锋。

### 5.2 炮台型

将凋零头、潜影贝或发射器固定在翅膀两侧。炮台不跟随身体转向，而是先锁定方向再齐射，方便玩家绕开弹道。

### 5.3 载荷型

将苦力怕、TNT、烟花和闪电放在飞行器下方。它们是“危险货物”，会通过蓄力、闪烁或点火表现下一次攻击。

### 5.4 装甲型

将监守者、铁傀儡或凋零骨架作为大型底盘。装甲本身不一定更快，但能提供更大的血条、分段护甲和区域攻击。

### 5.5 反差型

使用很小的骑乘者驾驶很大的底盘，或让早期 Boss 缩小成普通怪。这个尺寸变化是重要的数值降维反馈。

## 6. 阶段进化建议

### 阶段一：会飞的近战

幻翼 → 僵尸骑士·幻翼 → 烟花僵尸骑士·幻翼。

重点验证追踪、俯冲、挥砍和冲撞。

### 阶段二：会爆炸的飞行器

苦力怕·幻翼 → 闪电苦力怕·幻翼 → 烟花闪电苦力怕·幻翼。

重点验证爆炸圈、落雷预警和爆炸后的追击。

### 阶段三：远程压制

凋零头·幻翼 → 骷髅骑士·凋零 → 监守者·凋零·幻翼。

重点验证三向弹幕、直线音波和玩家绕场空间。

### 阶段四：全部词条装满

终焉合体保留前面所有能力，但使用轮流触发的攻击阶段，不同时释放所有技能。玩家需要从部件动作判断下一招。

## 7. 素材清单

第一版至少需要：

- 玩家方块飞行器：基础、受击、升级三个状态
- 幻翼翅膀：普通、受击、俯冲三个状态
- 小僵尸骑士：骑乘、挥砍、冲锋三个状态
- 苦力怕核心：正常、闪烁、爆炸三个状态
- 凋零头和骷髅弹
- 监守者胸腔和音波预警
- 烟花推进器和烟花弹
- 三叉戟弹、经验球、材料掉落
- 末地虚空背景、岛屿碎片、阴影和粒子

优先绘制“部件单元”，再通过组合装配怪物。这样新增怪物时只需复用已有部件，不必每次画完整角色。
